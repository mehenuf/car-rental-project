# Audit findings register, 2026-09-21

Result of a read-only, evidence-based audit of the gaps in the recovery prompt: two measured sweeps (keyboard, reduced motion, zoom, landscape, console), test gaps, security (two parts), devops, dead code, completeness and four design and slop reviews. Twelve units ran. Each P0 or P1 finding was re-checked by a second agent that tried to refute it; "confirmed" means it survived, and the severity column shows where the second agent changed it. P2 findings were not re-checked.

**Not run:** the home and cars design review and the architecture and token review were cut off by the session limit twice. The home and cars review was done by hand from screenshots (see design-gate-reviews.md); the token review was covered only by adding shared motion tokens and removing the last two backdrop blurs.

Status: 66 fixed, 17 partly fixed, 2 accepted or by design, 25 open (of 110).

Labels are the auditors' own: Measured, Observed, Inferred, Hypothesis, Recommendation. Migration 0018 fixes several database findings but **has not been applied to the production database**; see docs/GO-LIVE.md.
