# Screenshots

Save each image here using the exact filename listed below. The main [README.md](../../README.md) already links to these paths, so a correctly named file shows up automatically once it's added, no other edit needed.

| Filename | What to capture |
|---|---|
| `homepage-desktop.png` | The homepage at a desktop width (around 1440px). |
| `homepage-mobile.png` | The homepage at a phone width (around 375px). |
| `admin-dashboard-desktop.png` | The main `/admin` dashboard at a desktop width, logged in as an admin. |
| `admin-dashboard-mobile.png` | The main `/admin` dashboard at a phone width. |
| `chat-widget.png` | The chat widget open with an actual conversation in it, ideally with a car recommendation card visible. |
| `automation-booking-execution.png` | An n8n execution log showing a run triggered by a real booking. |
| `automation-hot-lead-execution.png` | An n8n execution log showing a run triggered by a scored lead that routed as "hot". |
| `automation-cold-lead-execution.png` | An n8n execution log showing a run triggered by a scored lead that routed as "cold". |
| `automation-google-sheet-rows.png` | The Google Sheet showing the rows those executions wrote. |

PNG or JPG both work. Before adding a screenshot, check it doesn't expose anything you don't want public: real customer names/emails in a booking or lead row, or API keys visible in an n8n node's parameters.
